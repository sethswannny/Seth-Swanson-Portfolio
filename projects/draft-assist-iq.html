Decision Engine Case Study

Draft Assist IQ ranks the pick, not just the player.

Draft Assist IQ is a live fantasy draft tool that weighs player value against roster needs, likely availability, league context, and opportunity cost. The goal is to answer a practical question: who should I take now, knowing who I can probably get later?

Problem

Raw rankings ignore draft context.

Static rankings are helpful, but they miss the central decision: whether the value at one position is scarce enough to take now. A decision engine needs to evaluate current roster gaps, league scoring, market behavior, and likely future availability together.

Approach

Score the decision from multiple angles.

The tool combines API player data, local draft state, roster construction, positional scarcity, projected availability, and configurable scoring weights. The output is a ranked recommendation with reasoning a user can understand quickly.

03

Explain the pick

What This Shows

Decision tools need both math and UX.

The interesting work is not only calculating a score. It is deciding which signals matter, keeping the state current, explaining the recommendation clearly, and making the interface useful under time pressure.
